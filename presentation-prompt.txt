Apply the following design system to make the presentation visually outstanding, not just content-complete:

Layout & Composition

Use a consistent grid — same margin, same title position, same content zone on every slide
One core idea per slide — avoid cramming multiple concepts on a single slide
Use asymmetric layouts (not everything centered) — image/visual on one side, text on the other, for visual interest
Generous white space — don't fill every inch, let content breathe
Visual hierarchy: title > key point > supporting detail, using size and weight, not just color

Typography

Max 2 font families: one bold/modern for headings, one clean/readable for body text
Large, confident slide titles (short phrases, not full sentences)
Short bullet lines (under 8-10 words each) — no paragraphs on slides
Use bold or color highlight on the ONE key word/number per slide instead of bolding everything

Color & Theme

Pick a small, consistent palette: 1 primary color (brand-ish), 1 accent color, 1 neutral background, 1 dark text color — nothing more
Use color purposefully — e.g., accent color only for the 70/30/10 split visualization or key numbers, not decoratively everywhere
Avoid default PowerPoint blue/gray theme — go for something that feels modern and slightly tech/robotics-coded (deep navy, teal, or graphite with a bright accent like orange or lime)

Visual Elements

Turn the 70-30-10 model into an actual visual (stacked bar, pie segment, or layered pyramid) — not a bullet list
Use simple icons (not clipart) for each field/vertical (agriculture, hospitality, industrial, etc.) instead of just text labels
For the "growth roadmap" slide, use a horizontal timeline/arrow graphic instead of a list
For the flagship elderly-care robot idea, use one clean illustrative graphic or diagram showing robot → sensor/voice input → reminder output flow

Slide-by-Slide UX Notes

Title slide: minimal — just team/project name placeholder, one clean visual (robot/drone silhouette), no clutter
Model/roadmap slides: diagram-first, text second
"Fields we can grow into" slide: icon grid layout (not a bulleted list) so it's scannable at a glance
Closing slide: simple, one-line forward-looking statement, no "thank you for your time" corporate closer — keep it casual since it's for a colleague

Motion/Interaction (if tool supports it)

Subtle entrance animations only (fade/slide-in), nothing flashy or distracting
No slide transitions like spin/zoom — keep it clean and fast-paced for a casual walkthrough

Overall Feel
